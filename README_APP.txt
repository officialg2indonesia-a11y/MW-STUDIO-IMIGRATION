MW IMIGRATION ASSET v1.5.1 BETA — APP WINDOWS

This package contains the Node bridge and the bundled Web UI.
The application is launched locally at http://127.0.0.1:8787.

UI theme:
- Deep black background
- Curved/pill navigation tabs
- White tab surface with black text
- Active tab uses black surface with white text
- White/black primary controls

Requires Node.js 18+.
